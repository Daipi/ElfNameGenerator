1️⃣ 部署 Cloudflare Worker
   → https://dash.cloudflare.com
   → Workers & Pages → Create Worker
   → 复制 cloudflare-worker.js 内容
   → Settings → Variables → 添加 HF_API_KEY
   ✓ 复制 Worker URL

2️⃣ 更新前端代码
   → 编辑 js/ai-generator.js
   → 第98行：设置 WORKER_URL
   ✓ 保存

3️⃣ 部署网站（任选其一）
   → GitHub Pages: Settings → Pages
   → Vercel: vercel 命令
   → Netlify: 拖放文件夹
   ✓ 完成！
